# Documentación del proyecto

Esta carpeta contiene los entregables documentales del proyecto de clasificación de cáncer de mama:

- `Manual_Despliegue_Nube_Cancer.pdf`: manual de despliegue en la nube listo para entrega.
- `Manual_Despliegue_Nube_Cancer.docx`: versión editable del manual.
- `Validacion_Pruebas_Cancer.pdf`: documento de validación, pruebas y conclusiones.
- `Validacion_Pruebas_Cancer.docx`: versión editable del documento de validación.

## Integración en GitHub

Extrae el archivo ZIP y copia la carpeta `docs` en la raíz del repositorio `cancermm`. Después confirma que esta carpeta se encuentre al mismo nivel que `backend`, `frontend`, `notebooks` y `README.md`.

Los archivos PDF son las versiones recomendadas para la entrega académica. Los archivos Word se incluyen como respaldo editable.
